# ImageManager

PyQt6で画像を一覧表示し、メタデータの検索、画像の移動・コピー、ワイルドカード出力を行うデスクトップアプリです。PNG、JPEG、WebPを対象にします。

## 起動

Python 3.10以降で、リポジトリのルートから実行します。

```powershell
python -m pip install -r requirements.txt
python main.py
```

`ImageManagerRun.bat`からも起動できます。設定は起動時の作業ディレクトリにある`app_settings.json`へ保存されます。既存の設定キーは維持されます。

## 使い方

- 「フォルダを選択...」または左側のフォルダツリーから画像フォルダを開きます。サブフォルダ検索の切り替え、ソート、プロンプトと生成情報のフィルタを利用できます。
- 「お気に入り」タブの追加ボタンで、現在のフォルダを登録します。登録済みフォルダをクリックすると開き、ドラッグで順序を変更できます。右クリックから登録解除、パスのコピー、Explorerで開く操作ができます。登録解除ではフォルダや画像は削除されません。
- 画像を選択して移動またはコピーします。コピーモードでは選択した順に番号が付き、その順でコピーします。処理中にキャンセルした場合も、成功済みのファイルは結果へ反映されます。
- 画像のダブルクリックでビューアを開きます。表示方式やサムネイルサイズなどは「設定」から変更できます。

## 構成

`SettingsStore`が設定の検証と原子的な保存を担当します。`FavoriteFolders`はWindowsパスと登録順を管理します。`ThumbnailController`はサムネイルとメタデータおよび読込世代、`SelectionController`は選択とコピー順を所有します。`FileOperationManager`はファイル操作の要求と結果反映を担当します。UIの組み立ては`UIManager`、ダイアログは`DialogManager`に分かれています。

## テスト

```powershell
python -m pytest -q
```

テストは一時ディレクトリを使用し、リポジトリの`app_settings.json`と実画像を変更しません。
